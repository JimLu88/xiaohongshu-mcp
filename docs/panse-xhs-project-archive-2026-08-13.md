# 畔色小红书项目归档总览（截至 2026-08-13）

## 1. 项目目标

项目以小红书为核心渠道，为畔色家具建立可持续的品牌传播、内容研究、账号矩阵、评论互动、文章库存和反馈优化系统。商业目标是扩大有效流量、引导品牌认知和产品转化，同时获取真实正向反馈。流量优先不等于允许造假、刷量、规避平台安全或制造虚假多数意见。

当前阶段是四周养号中的第 1 周：先通过真实阅读、角色一致的评论和少量关注建立内容兴趣图谱；正式文章发布尚未开始。

## 2. 系统架构

- 上游项目：`github.com/xpzouying/xiaohongshu-mcp`，当前仓库 HEAD `085da32`。

- `/healthz` 返回稳定身份；`/tachikoma/v1/contract` 返回业务适配器合同。

### 2.4 Tachikoma Style Lab 层

- 每条评论必须包含完整正文、相关图片、可见评论、身份、利益关系、事实边界和输出长度约束。
- plan、draft、semantic_review 都要求 `gpt-5.6-sol`，禁止 fallback。
- Style Lab 通过不代表可发送；必须进入人工待审队列。
- 本会话的语言校准已固化为：真人口语、不复述、不硬问、不上课、数字用阿拉伯数字、夸赞直接；官方评论在夸赞前先说明专业理由。

### 2.5 日常执行与证据层

- `scripts/xhs_warmup_runner.py` 负责计划、幂等键、阅读/停止证据和状态汇总；它本身不登录、不评论、不关注。
- `daily_runs/YYYY-MM-DD/` 保存每个 slot 的计划、深读、Style Lab 请求/回执、待审队列、发布回执和停止原因。
- 评论成功必须有四项平台证据，未验证的关注和评论不计数。
- `scripts/panse_content_registry.py` 与 SQLite 台账管理选题、素材权利、证据、实验、批准和发布状态。

### 2.6 文章生产层

- 已有文章 Style Contract v2、第一/第二波候选、预检队列、两批库存和 2026-08-11 来源包。
- 五个可长期写作方向：官方产品/服务、空间搭配、理性决策、尺寸动线、全球家具观察；创业与设计过程由官方号真实负责人署名承接。
- “国外图片”必须有来源和权利；AI/合成场景必须披露；建模过程要区分 AI 与人工环节。
- 当前仅允许离线生成和审核，禁止自动发布。

## 3. 关键方向与判断

1. 官方产品号：真实产品、版本、材料、结构、使用条件、售后和负责人署名解释。
2. 空间生活提案号：固定机位、图片 Mix、小户型、采光、颜色、家具组合和真实生活动作。
3. 家具配置/先别急着买：结构、材料、尺寸、安装、费用和未知条件；不做伪检测。
4. 放得下研究所：以净尺寸、门窗、柜门、通道和生活动作为核心。
5. 家具在别处：设计文化、工艺、修复、运输、装配和中国家庭适配；不泛化国家。
6. 透明验证与“别买任何东西”：作为栏目方法与语料，不建立假第三方身份。
7. 可补充的内容方向：国外案例本地验证、效果图/实物对照、AI 建模过程、创业成长、售后和长期使用。

## 4. 评论方法论的演进

早期评论的主要问题是只看标题、重复画面、以老师或评委口吻判断创作者、硬塞无意义问题、使用书面整理稿词。经过用户逐条校准后，现行规则为：

- 先完整读正文、相关图片和当前可见评论；
- 普通账号像同好，先具体共鸣、直接夸赞或问一个真能回答的问题；
- 不重复作者已经说过的事实，不描述显而易见画面；
- 不为了互动每条都问问题；
- 评价要贴近日常利益，例如怎么买、是否好用、是否省事、退货/运费/安装会不会麻烦；
- 用“买”而不是“下单”，用“那个”而不是“那组”，用“特别”替代过度书面连接词；
- 数字用阿拉伯数字；
- 官方号提供条件化专业意见：材料、结构、维修、尺寸、光线、AI/人工流程；没有专业增量就不发。
